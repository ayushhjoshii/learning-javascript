- Everything in HTML is a node eg. html tag, body tag, etc. are all nodes.
- Every HTML tag is a node but every node is not an HTML tag.
- It can be an element node or a text node. element node is the html tag, and text node is content inside of it.
- Whatever we see on a webpage is a part of DOM tree(Document
Object Model). 
- DOM(Document Object Model) is a programming interface that represents a webpage's HTML structure as a tree of objects in memory.
- When a browser loads a webpage, it parses the HTML and automatically creates this object-oriented representation.
- Things to learn in DOM manipulation:
    1. Select element form HTML.
    2. Change the text.
    3. Change HTML
    4. Change CSS
    5. Attribute change
    6. Event listeners
- There 4 ways to select elements form HTML: getElementById, getElementsByClassName, querySelector, querySelectorAll. The last two are mostly used nowadays.
